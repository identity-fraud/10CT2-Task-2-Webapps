For this we will be using Jekyll as the site generator and Github Pages for the hosting site.

Why/What is Github Pages?

Github Pages is a free static website website hosting service that integrates itself with Github. We will be using Github Pages over other providers as they are completely free for personal use and with its integration with Git allows for version control and collaboration.

Why/What is Jekyll?

Jekyll is a static site generator, meaning it allows for features like layouts and (technically) components, allowing for repetitive HTML files to instead linked from a foundational base layout. Jekyll is built in Github Pages and only requires one click, along with its Liquid tags features allows making blogs much easier.

1. Install Prerequisites & Jekyll

Before creating a Jekyll site, you need Ruby and RubyGems installed on your system. Run these commands in your terminal: 

        # Check if Ruby is installed
        ruby -v
        # Install Jekyll and Bundler gems
        gem install jekyll bundler

2. Create Your Local Jekyll Site

Create a new site structure and launch the local server: 

        # Create a new Jekyll site skeleton
        jekyll new my-blog
        # Navigate into your project folder
        cd my-blog
        # Start the local server
        bundle exec jekyll serve
Open your browser and navigate to http://localhost:4000 to view your running site.

3. Create a Base Post Layout

Create a file at _layouts/post.html to define how individual blog posts render: 

        ---
        layout: default
        ---
        <article class="post">
        <h1>{{ page.title }}</h1>
        <p class="post-date">{{ page.date | date: "%B %d, %Y" }}</p>
        
        <div class="post-body">
        {{ content }}
        </div>
        </article>

4. Write Your First Blog Post

Create a new file in the _posts directory. Jekyll requires post filenames to follow the strict YYYY-MM-DD-title.md naming convention (e.g. _posts/2026-09-20-my-first-post.md): 

        ---
        layout: post
        title: "My First Blog Post"
        summary: "Summary of my first blog post"
        tags: tagthings
        ---
        this post was generated using jekyll

5. Setup GitHub Repository & Deploy

Create a public repository on GitHub named your-username.github.io. Initialize Git in your project directory, commit your files, and push to GitHub: 

        git init
        git add .
        git commit -m "Setup Jekyll"
        git branch -M main
        git remote add origin username.github.io.git
        git push -u origin main
Go to your GitHub repository settings, navigate to Pages, set the source branch to main, and save. GitHub Pages will build your site and publish it at https://your-username.github.io.
