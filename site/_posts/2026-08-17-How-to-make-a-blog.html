For this we will be using Jekyll as the site generator and Github Pages for the hosting site.

Why/What is Github Pages?

Github Pages is a free static website website hosting service that integrates itself with Github. We will be using Github Pages over other providers as they are completely free for personal use and with its integration with Git allows for version control and collaboration.

Why/What is Jekyll?

Jekyll is a static site generator, meaning it allows for features like layouts and (technically) components, allowing for repetitive HTML files to instead linked from a foundational base layout. Jekyll is built in Github Pages and only requires one click, along with its Liquid tags features allows making blogs much easier.

1. Download Jekyll

Install Jekyll and Ruby using their installation instructions https://jekyllrb.com/docs/installation

2. Setup Github Pages

Create a Github repository and setup Github Pages with Jekyll workflow https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
